## 离线交付与核验

阶段备份放在仓库外 `member4_e5_e7_20261023/submission/`，避免将备份递归装入自身。ZIP 解压后以 `B-draft/` 为根，包含 Git 提交中的代码与报告、上述 `work/` 原始证据、`DELIVERY_MANIFEST.json` 和 `SHA256SUMS.json`。实际提交 SHA、文件数、未完成项及各文件哈希由清单记录；清单自身不列入其文件哈希表，ZIP 哈希单独保存在旁边的 `.sha256` 文件中。

备份不包含 `.git/`、本地凭据、`.env`、私钥、虚拟环境或缓存；保留无秘密的 `.env.example`。这是一份阶段备份，不代表 FAIL/PENDING 项已关闭，也不表示已经向教学平台提交。

可在任意系统使用 Python 标准库核验已解压内容（在 `B-draft/` 执行）：

```python
import hashlib, json
from pathlib import Path
root = Path.cwd()
expected = json.loads((root / "SHA256SUMS.json").read_text(encoding="utf-8"))
for name, digest in expected.items():
    assert hashlib.sha256((root / name).read_bytes()).hexdigest() == digest, name
print(f"verified {len(expected)} files")
```
